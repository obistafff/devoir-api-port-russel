 Port Russell – API & Interface d’administration

Application Node.js / Express / MongoDB pour la gestion du port de plaisance de Port Russell.

Le projet comprend :
- une API REST
- une interface d’administration en EJS
- une authentification par session
- une documentation API via Swagger

 Technologies utilisées
- Node.js
- Express
- MongoDB / Mongoose
- EJS
- express-session
- bcrypt
- Swagger (swagger-ui-express, swagger-jsdoc)

 Déploiement
